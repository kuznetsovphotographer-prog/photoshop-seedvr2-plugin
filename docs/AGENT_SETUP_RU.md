# Задание Для Codex, OpenCode Или Другого Агента

Эта инструкция помогает подготовить ComfyUI под **готовый SeedVR2 Upscaler 0.2.0**, не переписывая плагин.

## Сообщение, Которое Можно Передать Агенту

```text
Помоги установить и настроить локальный ComfyUI под Photoshop SeedVR2 Upscaler:
https://github.com/kuznetsovphotographer-prog/photoshop-seedvr2-plugin

Прочитай README.md, AGENTS.md, docs/COMFYUI_SETUP_RU.md,
docs/AGENT_SETUP_RU.md и docs/comfyui-setup-manifest.json.
Проверь мою ОС, GPU/VRAM, драйвер, свободное место и наличие ComfyUI.
Если готовая установка уже есть, сначала проверь её и не ломай.
Если её нет, предложи подходящий способ; для отдельной Windows NVIDIA-сборки
можно использовать официальный Portable. Уточни папку установки.
Перед скачиванием сообщи объём: около 17 GB моделей плюс окружение.

После согласования подготовь ComfyUI, нужные custom nodes и ровно две модели.
Используй Python выбранной сборки. Проверь SHA256, API на 127.0.0.1:8188,
регистрацию узлов и доступность моделей. Если я разрешу GPU-тест,
выполни маленький тест через API и дождись результата.
Исходники плагина, workflow, модель и установочный CCX без моего запроса не меняй.
В конце дай пути, способ запуска и честный отчёт: что реально проверено,
а что ещё нужно проверить вручную в Photoshop.
```

Ссылка на репозиторий сама по себе не даёт агенту доступа к компьютеру. Нужен локальный агент с разрешённым доступом к выбранной папке и терминалу. Агент в удалённой среде может подготовить команды, но это не установка на пользовательский Windows-компьютер.

## Порядок Работы

1. **Инвентаризация:** ОС/архитектура, GPU, VRAM, драйвер, место на диске, существующие процессы и установки ComfyUI. Для NVIDIA можно использовать `nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv`. Наличие команды ещё не гарантирует CUDA в Python.
2. **Выбор:** не устанавливать вторую копию без причины. Для новой Windows NVIDIA-сборки рассмотреть Portable; для действующего Stability Matrix/Desktop использовать именно выбранный экземпляр.
3. **Согласование:** папка, размер загрузок, запускаемые процессы. Не скачивать весь репозиторий моделей. Если железо явно не подходит 7B FP16, объяснить ограничение, а не обещать помощь tiled-режима.
4. **Среда:** найти executable Python данного ComfyUI. Свериться с актуальными официальными требованиями; не использовать глобальный pip и не менять существующие Torch/CUDA автоматически.
5. **Узлы:** установить numz/ComfyUI-SeedVR2_VideoUpscaler и requirements в это окружение. Не клонировать поверх существующей папки. Проверить импорт по логу и перезапустить только согласованный экземпляр.
6. **Модели:** загрузить только два файла из [manifest](comfyui-setup-manifest.json), проверить размер и SHA256. Существующие исправные файлы повторно не скачивать. Незавершённые файлы держать с суффиксом .part, не выдавать за готовые веса.
7. **Сервер:** localhost, порт 8188. Сначала определить, кто занял порт; не останавливать чужие процессы. Фоновый запуск делать без видимого окна, с логом и PID. Если пользователь хочет видимую консоль для ручного управления, запуск согласовать отдельно.
8. **Проверка:** выполнить GET-проверки из [инструкции установки](COMFYUI_SETUP_RU.md), сверить class_type и inputs workflow со схемами object_info.
9. **GPU-тест:** только после разрешения, по сценарию ниже. Если тест нельзя выполнить, так и написать.
10. **Photoshop:** подготовить ссылку на CCX/ZIP и порядок установки. Ручную проверку панели не подменять проверкой HTTP.

Загрузки крупных файлов делайте с повторными попытками/возобновлением, например curl с `--fail --location --continue-at - --retry 3`, сохраняя в .part. После полного скачивания и проверки хеша переименуйте файл, не затирая существующий. Не отключайте TLS, антивирус или системные политики ради загрузки.

## Контракт Совместимости

Источник истины: [API workflow плагина](../plugin/photoshop-seedvr2-plugin/workflows/seedvr2_simple_image_upscale_api.json).

| ID | class_type | Назначение |
| --- | --- | --- |
| 16 | LoadImage | Загруженный PNG |
| 17 | JoinImageWithAlpha | Alpha-цепочка |
| 14 | SeedVR2LoadDiTModel | seedvr2_ema_7b_fp16.safetensors, cuda:0 |
| 13 | SeedVR2LoadVAEModel | ema_vae_fp16.safetensors, cuda:0 |
| 10 | SeedVR2VideoUpscaler | resolution и seed |
| 15 | SaveImage | Выход результата |

Сохранять batch_size=1, uniform_batch_size=true, VAE encode/decode tiling 1024/128, color_correction=lab, max_resolution=0 и alpha-цепочку. Не добавлять Torch Compile. При несовместимой схеме узлов сообщить об этом и запросить решение; не «чинить» стабильный workflow и не подменять модель FP8/GGUF/3B незаметно.

Узлы имеют номер версии в метаданных исходного workflow, но этот номер не является автоматически проверенным lock-файлом окружения. Название свежего ComfyUI-релиза в инструкции также не означает пройденную интеграционную проверку.

## Маленький GPU-Тест Через API

Сначала предупредить о загрузке тяжёлой модели и возможном OOM, даже при маленькой картинке. Использовать согласованную тестовую картинку без чувствительных данных, не оригинал из рабочей папки пользователя.

1. Подготовить небольшой PNG, например 256 × 256, во временной папке.
2. Отправить multipart POST `/upload/image`: файл в поле image, type=input. В ответе сохранить name/subfolder/type.
3. Прочитать отдельную копию API workflow. Подставить в node 16.inputs.image имя из ответа, включая subfolder; установить resolution=500 и целочисленный seed в node 10. Не сохранять эти изменения в исходный workflow.
4. POST `/prompt` с JSON `{"prompt": workflow, "client_id": uniqueId}`. Проверить HTTP-статус, error/node_errors и наличие prompt_id.
5. Дождаться `/history/{prompt_id}` либо WebSocket-событий; отличать очередь, исполнение, ошибку и таймаут. Наличие prompt_id ещё не означает успешную генерацию.
6. Найти PNG в outputs узла 15, скачать через `/view` с filename/subfolder/type из ответа. Проверить читаемость и размер результата.
7. При ошибке сохранить короткую диагностику: стадия, prompt_id, текст ошибки, версии среды. Не запускать бесконечные повторы и не прерывать чужую очередь.
8. Временные файлы убирать только внутри своей проверенной временной папки. ComfyUI input/output и пользовательские модели без запроса не удалять.

Описание маршрутов: [официальный API ComfyUI](https://docs.comfy.org/development/comfyui-server/comms_routes).

Этот тест проверяет один проход SeedVR2, **не** tiled-сборку, Undo, Photoshop Actions или размещение слоёв. Для них нужны [проверки в реальном Photoshop](../plugin/photoshop-seedvr2-plugin/MANUAL_TEST_RU.md).

## Что Включить В Отчёт

- Метод установки, фактические пути ComfyUI, Python и моделей.
- Версии/commit ComfyUI и узлов, Python, Torch, CUDA и драйвер.
- Размеры/SHA256 двух моделей и результат проверки.
- Команда/launcher запуска, адрес сервера, лог и PID при фоновом запуске.
- Результаты API-проверок отдельно от реальной генерации.
- Пройден ли GPU-тест, путь к PNG и размеры, либо точный блокер.
- Что остаётся сделать вручную в Photoshop.

Не называйте сборку проверенной, если скачаны только файлы или открылась главная страница ComfyUI.
