# Photoshop Actions И Пакетная Обработка

Для записи и воспроизведения UXP-команд нужен **Photoshop 25.0+**. Для tiled-настроек используйте **SeedVR2 0.2.0**.

## Запись Операции

1. Откройте `Window -> Actions` и создайте операцию.
2. Включите запись.
3. Настройте размер, New Window и Tiled Upscale; выберите 2/4/6 частей.
4. Нажмите Upscale и дождитесь завершения.
5. Остановите запись.

Должен появиться один шаг `SeedVR2 Upscale`. Он хранит режим размера, множитель, короткую сторону, New Window, состояние tiled-режима и количество частей.

**Seed не фиксируется:** при каждом запуске выбирается новый случайный seed. Внутри одной tiled-операции он общий для всех частей. Это не гарантирует попиксельно одинаковый результат при повторном воспроизведении.

## Совместимость Со Старыми Экшенами

Шаги 0.1.1 без полей `tiledEnabled` и `tileCount` выполняют обычный апскейл, независимо от текущей подсветки кнопок в панели. Для обработки по частям запишите новый шаг в 0.2.0.

## Проверка

Откройте другой тестовый документ и воспроизведите операцию. Проверьте, что использованы записанные параметры, а не текущие настройки панели. Если в шаге было выделение, заранее подготовьте нужную область или добавьте отдельный шаг выделения.

## Пакетная Обработка

Обычная последовательность для папки файлов:

```text
SeedVR2 Upscale
Save
Close
```

Выберите **New Window OFF**, чтобы следующие шаги сохраняли и закрывали текущий документ. Без выделения документ увеличивается; с выделением локальный результат возвращается в старые границы.

Сначала проверьте действие на двух копиях файлов. Затем откройте `File -> Automate -> Batch`, выберите действие, источник и правила сохранения. Проверьте, что сохранение не перезаписывает единственные оригиналы.

ComfyUI должен оставаться запущенным. Файлы и части обрабатываются последовательно. Ошибка ComfyUI или защиты исходника передаётся Photoshop и может остановить пакет. Автоматического продолжения с пропущенными частями нет.

Если после сбоя возврата появился Open Last Result, его можно открыть вручную в текущем сеансе плагина. Для пакетной автоматизации это не замена успешному завершению шага.

## Если Шаг Не Записался

Проверьте версию Photoshop и установленного CCX, включите запись до Upscale и перезапустите Photoshop после обновления. Две версии с одним plugin ID одновременно использовать нельзя.
