# Photoshop Actions и пакетная обработка

## Требование

Для записи команд UXP-плагина нужен Adobe Photoshop 25.0 или новее. Установите SeedVR2 Upscaler версии `0.1.1` или новее.

## Запись операции

1. Откройте `Window -> Actions`.
2. Создайте новую операцию.
3. Нажмите кнопку записи.
4. В панели SeedVR2 выберите режим, размер и `New Window`.
5. Нажмите `Upscale` и дождитесь завершения.
6. Остановите запись операции.

В Actions должен появиться один шаг:

```text
SeedVR2 Upscale
```

Шаг хранит:

- `Scale Multiplier` или `Shortest Side Limit`;
- множитель `2x`, `3x` или `4x`;
- точное значение короткой стороны;
- состояние `New Window`;
- seed конкретного запуска.

## Проверка воспроизведения

1. Откройте другой тестовый документ.
2. Запустите записанную операцию.
3. Убедитесь, что применились параметры записанного шага, а не текущее состояние панели.

## Пакетная обработка

Для обработки папки обычно удобна такая операция:

```text
SeedVR2 Upscale
Save
Close
```

Используйте `New Window OFF`, чтобы сохранение и закрытие относились к текущему документу.

После проверки на двух небольших файлах откройте:

```text
File -> Automate -> Batch
```

Выберите операцию, входную папку и правила сохранения.

## Важные ограничения

- ComfyUI должен оставаться запущенным всю пакетную обработку.
- Каждый файл обрабатывается последовательно и может занимать значительное время.
- Не используйте `New Window ON`, если следующие шаги экшена должны сохранять исходный документ.
- Сначала проверьте операцию на копиях файлов.
- Ошибка ComfyUI во время playback останавливает шаг и передается Photoshop.

## Если шаг не записывается

- проверьте версию Photoshop;
- убедитесь, что установлена версия плагина `0.1.1+`;
- включите запись Actions до нажатия `Upscale`;
- перезапустите Photoshop после обновления CCX;
- при сомнении удалите старую версию BAT-файлом и установите CCX заново.
