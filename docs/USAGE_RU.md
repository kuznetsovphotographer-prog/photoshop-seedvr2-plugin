# Использование SeedVR2 Upscaler 0.2.0

## Первый Запуск

1. Запустите ComfyUI и дождитесь готовности `http://127.0.0.1:8188`.
2. Откройте тестовую фотографию в Photoshop. Для обработки фрагмента создайте выделение.
3. Выберите размер, `New Window` и при необходимости `Tiled Upscale`.
4. Проверьте строку расчёта, затем нажмите `Upscale`.

Первый запуск может быть долгим: ComfyUI загружает модели. Во время генерации настройки блокируются. Не меняйте исходный документ до завершения.

## Scale Multiplier

Кнопки `2x / 3x / 4x` масштабируют ширину и высоту. Нажатие кнопки включает этот режим. При переходе в `Shortest Side Limit` подсветка множителей снимается.

При выключенном tiled-режиме предел 2500 px относится к короткой стороне всего результата. При включённом он относится к каждой части, включая перекрытие. Если выбранный множитель превышает предел, общий масштаб уменьшается.

## Shortest Side Limit

Клик по числовому полю включает режим. Введите число с клавиатуры; оно нормализуется при потере фокуса или запуске.

- Диапазон: `500–2500 px`, с чётным округлением.
- По умолчанию: `2000 px`.
- Tiled OFF: короткая сторона итогового изображения.
- Tiled ON: короткая сторона **отдельного фрагмента**.

Точная цель на часть не означает фиксированный размер всей сборки. Из-за перекрытий четыре фрагмента по 2000 px не дают ровно 4000 px. Смотрите рассчитанные размеры под кнопками частей.

## Tiled Upscale

Включите тумблер или нажмите `2 parts`, `4 parts`, `6 parts`. Нажатие кнопки сразу включает обработку по частям. По умолчанию режим выключен, сохранённый выбор: 4 части. При OFF ни одна кнопка частей не подсвечивается.

| Части | Сетка |
| --- | --- |
| 2 | Разрез вдоль длинной стороны: 2 столбца для горизонтального, 2 ряда для вертикального кадра |
| 4 | 2 × 2 |
| 6 | 3 × 2 для горизонтального и квадратного; 2 × 3 для вертикального |

Плагин один раз сохраняет видимые пиксели источника, вырезает части с перекрытием до 128 исходных пикселей, отправляет их в SeedVR2 **строго по очереди** и собирает один PNG. Для маленьких изображений перекрытие уменьшается. Один seed используется на всю операцию.

Пересечения смешиваются плавными нормализованными весами по обеим осям, с учётом alpha. Сборка выполняется через Photoshop Imaging API блоками до 1024 × 128 px, в sRGB, 8 bit RGBA.

### Пример Размера

На записи автора: исходник **1800 × 2417 px**, множитель **2x**, **4 части**. Результат: **3600 × 4834 px**.

Каждая часть увеличилась вдвое, поэтому сборка тоже увеличилась вдвое по каждой стороне. Число частей не добавляет ещё один множитель. Пикселей стало примерно в четыре раза больше.

### Когда Полезны Части

Если весь кадр не помещается в видеопамять, попробуйте 4 или 6 частей либо меньшую цель на часть. Вес модели от этого не уменьшается. Режим не гарантирует работу на любой GPU или ускорение.

При одинаковом `2x` переход с 2 на 4 части обычно сохраняет тот же итоговый масштаб, если не срабатывает лимит. В точном режиме смена числа частей может изменить итоговый размер, поскольку цель задана для каждого фрагмента.

## New Window И Выделение

| Источник | OFF | ON |
| --- | --- | --- |
| Весь документ | Текущий документ заменяется увеличенной картинкой и сводится в один raster-слой | Результат открывается новым документом, исходник не меняется |
| Есть выделение | Новый слой `SeedVR2 Upscale` возвращается в исходные границы выделения | Увеличенная рамка выделения открывается новым документом |

Любое непустое выделение обрабатывается как прямоугольная рамка вокруг него. Tiled-режим работает и с целым документом, и с этой рамкой.

**При выделении + New Window OFF холст и размер фрагмента в документе остаются прежними.** Апскейл добавляет детали, после чего результат подгоняется обратно. Для увеличенного фрагмента отдельным изображением включите New Window.

## Прогресс И Stop

Синяя полоса общая для экспорта, всех частей, сборки и возврата. Подписи показывают этап: `Part 2/6`, `Stitching...`, `Applying...`. При переходе к следующей части прогресс не сбрасывается.

Во время обработки нажмите `Stop` на рабочей кнопке. Плагин отправит interrupt в ComfyUI и не запустит следующие части. Текущий CUDA-шаг может завершаться не сразу. Ошибка любой части отменяет всю операцию: неполная сборка не вставляется.

## Undo И Защита Исходника

Замена всего документа и возврат выделения выполняются одним undo-шагом. Перед изменением оригинала проверяются ID документа, его размеры и состояние истории.

Ошибка `The Photoshop document changed...` означает срабатывание этой защиты, а не автоматически нехватку памяти. Подробности: [ошибки и решения](TROUBLESHOOTING_RU.md).

Если PNG уже собран, но вернуть его в исходник не удалось, появляется **Open Last Result**. Нажмите её до закрытия или перезагрузки плагина: готовый PNG откроется новым документом, повторная генерация не нужна. Плагин хранит только последний такой результат в текущем сеансе.

## Проверка Качества

Осмотрите стыки при 100%, особенно линии, волосы, лицо, фактуру и текст. Перекрытия смягчают переходы, но соседние генерации могут отличаться. Большее число частей не гарантирует более точные детали или меньше галлюцинаций.

PNG ограничен 30000 px по каждой стороне. Для крупной сборки нужны оперативная память и свободный scratch-диск Photoshop.
