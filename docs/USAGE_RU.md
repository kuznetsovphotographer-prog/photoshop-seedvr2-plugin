# Использование SeedVR2 Upscaler

## Основной порядок

1. Запустите ComfyUI и дождитесь полной загрузки.
2. Откройте фотографию в Photoshop.
3. При необходимости создайте выделение.
4. Выберите способ расчета размера.
5. Выберите `New Window ON` или `OFF`.
6. Нажмите `Upscale`.

Во время обработки настройки блокируются, кнопка меняется на `Working...` и `Stop`, а нижняя синяя полоса показывает прогресс ComfyUI.

## Scale Multiplier

Кнопки `2x`, `3x`, `4x` задают множитель короткой стороны. Если расчет превышает `2500 px`, плагин автоматически ограничивает короткую сторону до `2500 px`.

Нажатие на любую кнопку множителя сразу активирует режим `Scale Multiplier`.

## Shortest Side Limit

Этот режим задает точную длину короткой стороны результата в пикселях.

- минимум: `500 px`;
- значение по умолчанию: `2000 px`;
- максимум: `2500 px`.

Клик по полю размера сразу активирует `Shortest Side Limit`. Введите число с клавиатуры. Значение нормализуется при потере фокуса или запуске.

## New Window

### Без выделения

- `OFF`: весь текущий документ заменяется увеличенной версией и сводится в один raster-слой;
- `ON`: увеличенная версия открывается новым документом, исходник не меняется.

### С выделением

- `OFF`: видимые пиксели в bounding box выделения улучшаются, затем результат помещается в исходный документ новым слоем `SeedVR2 Upscale` в прежних границах;
- `ON`: увеличенный фрагмент открывается отдельным документом.

Для лассо и других непустых выделений используется прямоугольная рамка вокруг выделения.

## Undo

- замена всего документа выполняется одним шагом истории;
- возврат локального результата в исходный документ выполняется одним шагом и удаляется одним `Undo`.

## Stop

Во время генерации наведите курсор на рабочую кнопку и нажмите `Stop`. Плагин отправит interrupt в ComfyUI, очистит локальное ожидание и не будет применять поздний результат.

## Защита документа

Перед возвратом результата плагин проверяет ID документа, размеры и состояние истории. Если документ был изменен во время рендера, результат не применяется. Это защищает работу от вставки в уже изменившийся файл.

## Практические советы

- Для первого теста используйте небольшое RGB-изображение и `2x`.
- Проверяйте результат при масштабе 100% и выше.
- Локальное улучшение удобно для лица, одежды и областей, ранее измененных генеративными инструментами.
- SeedVR2 может дорисовывать детали, поэтому результат нужно оценивать, а не принимать автоматически.
- Для серии файлов используйте Photoshop Actions и `New Window OFF`.
