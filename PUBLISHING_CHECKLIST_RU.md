# Чек-лист публикации на GitHub

## До загрузки

- подтвердить право на публикацию демонстрационных фото и видео;
- проверить CCX на чистой установленной версии Photoshop;
- вручную выполнить workflow в актуальном ComfyUI;
- проверить `2x`, `Shortest Side Limit`, выделение, `New Window`, Stop и Actions;
- убедиться, что в репозитории нет моделей, токенов, приватных путей и временных логов.

## Создание репозитория

1. Создайте пустой публичный репозиторий, например `seedvr2-photoshop-upscaler`.
2. Загрузите содержимое этой папки в корень репозитория.
3. Не помещайте саму папку `seedvr2-photoshop-upscaler` еще на один уровень внутрь.
4. Проверьте отображение README, GIF и изображений.
5. Добавьте Topics: `photoshop`, `uxp`, `comfyui`, `seedvr2`, `upscaler`, `ai-image`.

## GitHub Release

1. Создайте тег `v0.1.1`.
2. Используйте текст из `RELEASE_NOTES_v0.1.1.md`.
3. Прикрепите `ccx/com.local.photoshop.seedvr2-upscaler_PS.ccx` как release asset.
4. Прикрепите `ccx/SeedVR2-Upscaler-v0.1.1-Windows.zip` как готовый комплект установки.

## После публикации

- открыть все ссылки README из браузера без авторизации;
- скачать CCX с GitHub и проверить установку именно скачанного файла;
- добавить ссылку на репозиторий в описание YouTube-ролика;
- для следующей версии увеличить номер в manifest, CCX, release notes и теге.
