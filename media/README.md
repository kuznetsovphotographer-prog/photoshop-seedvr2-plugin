# Demonstration Assets

New v0.2.0 demonstrations come from the seven screen recordings and four JPEG files supplied by the project author for this publication. No new MP4 files are published.

| Source recording | Published GIF |
| --- | --- |
| 1. Installation | `gif/install.gif` |
| 2. Find the plugin in Photoshop | `gif/open-panel.gif` |
| 3. Panel controls | `gif/tiled-controls.gif` |
| 4. Start ComfyUI | `gif/start-comfyui.gif` |
| 5. Configure and run four-part upscaling | `gif/tiled-run.gif` |
| 6. Inspect before/after | `gif/before-after-in-photoshop.gif` |
| 7. Compare image dimensions | `gif/resolution-check.gif`, `images/source-size.jpg`, `images/result-size.jpg` |

Screen GIFs are cropped, resized, sampled at a reduced frame rate and palette-quantized. They are excerpts, not generation-time benchmarks. The resolution GIF alternates two actual dialog frames from recording 7.

`images/tiled-before-after.jpg` and `gif/detail-comparison.gif` use the author's supplied before/after detail JPEGs. The after crop is registered to the before crop using a similarity transform, then both are cropped and resized to the same presentation scale. No sharpening, skin retouching, generative editing or synthetic details were added. These are normalized comparisons, not native-pixel 1:1 crops.

`images/before-detail.jpg`, `images/after-detail.jpg` and `images/source-photo.jpg` preserve the supplied fields of view and dimensions, re-encoded without metadata for publication. `images/plugin-panel-v0.2.0.jpg` is a crop of the actual Photoshop panel screenshot, not a browser mockup.

Legacy `local-selection-demo.gif` and its associated images are retained as an earlier selection-mode example. Photographs and recordings remain the author's materials; no separate media license is granted here.
