# SeedVR2 Upscaler 0.2.0

Исходники UXP-плагина, соответствующие опубликованному CCX 0.2.0.

- [Руководство пользователя](../../docs/USAGE_RU.md)
- [Установка](../../docs/INSTALLATION_RU.md)
- [Архитектура, тесты и сборка](../../docs/DEVELOPMENT_RU.md)
- [Ручная проверка](MANUAL_TEST_RU.md)

В UXP Developer Tool загрузите manifest.json из этой папки. Сначала сделайте Unload старого экземпляра с тем же plugin ID.

Tiled Upscale использует 2/4/6 перекрывающихся частей, последовательные запросы SeedVR2 и Photoshop Imaging API для сборки. Доступны все сочетания New Window и выделения.

2500 px ограничивает короткую сторону одной части при Tiled ON и всего результата при Tiled OFF. Параметры размера и вывода записываются в Actions; старые шаги без tiled-полей запускают обычный режим.

Проверка: node tests/run-tests.js. Реальная проверка Photoshop, установки и GPU выполняется отдельно.
