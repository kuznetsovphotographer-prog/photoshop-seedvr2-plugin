# SeedVR2 Upscaler for Photoshop

UXP-плагин Photoshop для локального апскейла изображений через SeedVR2 и ComfyUI.

## Поведение

- `New Window OFF` без выделения: плагин апскейлит видимое изображение и заменяет текущий документ одним сведенным слоем в том же окне.
- `New Window ON` без выделения: плагин апскейлит видимое изображение и открывает результат отдельным новым документом, не меняя исходный документ.
- `New Window OFF` с любым непустым выделением: плагин берет прямоугольную рамку выделения, апскейлит видимые пиксели внутри нее и возвращает результат в исходный документ новым слоем, трансформированным обратно в старые границы выделения.
- `New Window ON` с любым непустым выделением: плагин берет прямоугольную рамку выделения, апскейлит ее и открывает результат отдельным новым документом.
- Во всех сценариях ComfyUI получает PNG через `http://127.0.0.1:8188`.

## Размер

- `Scale Multiplier`: `2x`, `3x`, `4x`.
- `Shortest Side Limit`: точная длина короткой стороны от `500` до `2500 px`.
- Итоговая короткая сторона автоматически ограничивается до `2500 px`.

## Зафиксированные оптимизации

Плагин принудительно включает:

- VAE encode tiling: `1024`, overlap `128`.
- VAE decode tiling: `1024`, overlap `128`.
- `uniform_batch_size: true`.
- `batch_size: 1`.

Torch Compile намеренно отключен для одиночных фотографий.

## Загрузка через UXP Developer Tool

1. Запустите Photoshop и Adobe UXP Developer Tool.
2. Нажмите `Add Plugin`.
3. Выберите `manifest.json` из этой папки.
4. Нажмите `Load`.
5. Откройте `Plugins -> SeedVR2 Upscaler -> SeedVR2 Upscaler`.

После изменения исходников используйте `Unload -> Load`.

Экспорт и возврат результата выполняются нативными средствами Photoshop внутри `executeAsModal`: merged duplicate, crop, `saveAs.png`, временное открытие результата и копирование raster-слоя. Критический путь не использует Canvas.

## Photoshop Actions и пакетная обработка

Плагин записывает нажатие `Upscale` как один шаг `SeedVR2 Upscale` в панели
Photoshop Actions. В шаге сохраняются выбранный режим размера, множитель,
`Shortest Side Limit` и состояние `New Window`.

1. Откройте `Окно -> Операции` (`Window -> Actions`).
2. Создайте новую операцию и включите запись.
3. Настройте SeedVR2 и нажмите `Upscale`.
4. Дождитесь завершения и остановите запись операции.
5. Запустите записанную операцию на другом документе или через
   `Файл -> Автоматизация -> Пакетная обработка`.

Для пакетной обработки обычно используйте `New Window OFF`, чтобы результат
оставался в текущем документе и следующие шаги экшена могли сохранить и закрыть его.
Запись и воспроизведение шагов UXP-плагина требуют Photoshop 25.0 или новее.
