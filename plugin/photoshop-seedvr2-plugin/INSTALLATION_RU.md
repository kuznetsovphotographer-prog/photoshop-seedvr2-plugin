# Установка SeedVR2 Upscaler

Для готового пакета используйте [общую инструкцию](../../docs/INSTALLATION_RU.md).

Для разработки выгрузите прежний экземпляр в UXP Developer Tool, нажмите Add Plugin, выберите manifest.json из этой папки и Load.

Идентификатор сохранён: com.local.photoshop.seedvr2-upscaler. Одновременно загружать старую и новую версии нельзя.

Photoshop 24.0+: обычный режим; 24.4+ с Imaging API: Tiled Upscale; 25.0+: Actions.
