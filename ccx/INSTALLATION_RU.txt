SeedVR2 Upscaler 0.2.0 / Windows

1. Распакуйте ZIP целиком. Не запускайте BAT из окна архива.
2. Оставьте com.local.photoshop.seedvr2-upscaler_PS.ccx рядом с BAT-файлами.
3. Выгрузите Developer Tool-копию через Unload, если она использовалась.
4. Закройте Photoshop.
5. Запустите INSTALL_SEEDVR2_UPSCALER.bat, подтвердите права и приглашение в консоли.
6. Дождитесь успешного завершения, затем перезапустите Photoshop.
7. Меню: Plugins -> SeedVR2 Upscaler -> SeedVR2 Upscaler.

Нужен Adobe Creative Cloud Desktop. BAT вызывает официальный Adobe UPIA.
Обновление устанавливается поверх SeedVR2 с тем же plugin ID.

Удаление: закройте Photoshop, запустите UNINSTALL_SEEDVR2_UPSCALER.bat.
ComfyUI и модели остаются на компьютере.

Перед генерацией запустите ComfyUI на http://127.0.0.1:8188.
Установите узлы ComfyUI-SeedVR2_VideoUpscaler и нужные модели.
Workflow использует 7B FP16, модели в архив не входят.
JSON в комплекте является API-шаблоном; плагин сам подставляет изображение.

Photoshop: 24.0+ обычный режим, 24.4+ с Imaging API tiled, 25.0+ Actions.
Tiled Upscale: 2/4/6 частей по очереди. 2500 px: предел короткой стороны части.
Точный итог зависит от исходника и показан в панели. Части не уменьшают веса модели.
Не редактируйте исходник во время работы.

Руководство: https://github.com/kuznetsovphotographer-prog/photoshop-seedvr2-plugin
Ошибки Adobe: C:\ProgramData\Adobe\UPI\Log\Upia.log
