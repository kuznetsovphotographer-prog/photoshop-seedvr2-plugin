# Установка SeedVR2 Upscaler

## Способ 1. BAT-файл: рекомендуется

1. Закройте Photoshop.
2. Убедитесь, что рядом лежат:
   - `com.local.photoshop.seedvr2-upscaler_PS.ccx`
   - `INSTALL_SEEDVR2_UPSCALER.bat`
3. Запустите `INSTALL_SEEDVR2_UPSCALER.bat`.
4. Если Windows покажет запрос контроля учетных записей, разрешите запуск.
5. После сообщения `SeedVR2 Upscaler is installed` откройте Photoshop.
6. Панель находится в меню:
   `Подключаемые модули -> SeedVR2 Upscaler -> SeedVR2 Upscaler`.

## Способ 2. Двойной щелчок по CCX

1. Закройте Photoshop.
2. Для надежности скопируйте `.ccx` в короткий путь на диске `C:`, например:
   `C:\Temp\SeedVR2Upscaler`.
3. Дважды щелкните по `.ccx`.
4. Подтвердите установку в Creative Cloud Desktop.
5. Перезапустите Photoshop.

Если окно мелькнуло, но плагин не появился, используйте BAT-файл.

## Способ 3. Adobe UXP Developer Tool

Используйте этот способ только для разработки или тестирования исходников.

1. Откройте Photoshop и Adobe UXP Developer Tool.
2. Нажмите `Add Plugin`.
3. Выберите `manifest.json` из корня исходников плагина.
4. Нажмите `Load`.
5. После изменений используйте `Reload` или `Unload -> Load`.

## Что должно быть запущено для работы

Плагин использует локальный ComfyUI:

```text
http://127.0.0.1:8188
```

Перед апскейлом запустите ComfyUI через Stability Matrix или вашим обычным способом.
В ComfyUI должны быть установлены SeedVR2-ноды и нужные модели SeedVR2/VAE.

## Известная проблема Windows: ошибка `-198`

На некоторых компьютерах Adobe UPIA некорректно обрабатывает пользовательский
путь, если установка запускается с другого диска, например `E:`. Установщик может
попытаться открыть путь без буквы диска:

```text
\Users\User\AppData\Roaming\Adobe
```

В результате валидный `.ccx` не устанавливается. BAT-файл обходит этот баг:
переключает рабочую папку на `C:\`, запускает официальный Adobe UPIA и проверяет,
зарегистрирован ли плагин.

Не начинайте с удаления Photoshop, Creative Cloud или переустановки Windows.
Сначала используйте BAT-файл.

## Если установка не подтверждена

Проверьте журналы:

```text
C:\ProgramData\Adobe\UPI\Log\Upia.log
C:\ProgramData\Adobe\UPI\Log\EMCL.log
```

Если BAT-файл сообщает, что UPIA не найден, установите или восстановите Adobe
Creative Cloud Desktop.

## Обновление установленного плагина

Для новой версии сохраните прежний ID плагина, увеличьте номер версии в
`manifest.json`, соберите новый `.ccx` и запустите новый
`INSTALL_SEEDVR2_UPSCALER.bat`. Обычно Adobe UPIA заменяет старую локальную
версию новой автоматически.

Если обновление поверх старой версии не сработало:

1. Закройте Photoshop.
2. Запустите `UNINSTALL_SEEDVR2_UPSCALER.bat`.
3. После сообщения `SeedVR2 Upscaler is removed` запустите новый
   `INSTALL_SEEDVR2_UPSCALER.bat`.
4. Перезапустите Photoshop.

## Удаление плагина

Для локально установленного `.ccx` кнопка с тремя точками в Creative Cloud
Desktop может быть недоступна. Используйте штатный удалитель Adobe:

```text
UNINSTALL_SEEDVR2_UPSCALER.bat
```

Он вызывает официальный Adobe UPIA с командой:

```text
/remove "SeedVR2 Upscaler"
```
