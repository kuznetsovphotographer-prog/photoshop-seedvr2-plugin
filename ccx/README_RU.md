# Быстрая установка

1. Закройте Photoshop.
2. Запустите `INSTALL_SEEDVR2_UPSCALER.bat`.
3. Подтвердите запрос Windows.
4. Перезапустите Photoshop.
5. Откройте `Plugins -> SeedVR2 Upscaler -> SeedVR2 Upscaler`.

ComfyUI должен быть запущен на `http://127.0.0.1:8188`, а приложенный SeedVR2 workflow должен успешно выполняться вручную.

Для удаления запустите `UNINSTALL_SEEDVR2_UPSCALER.bat`.

Подробная инструкция: [../docs/INSTALLATION_RU.md](../docs/INSTALLATION_RU.md).
